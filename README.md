# Student Management API (FastAPI)

A simple REST API built with FastAPI to manage students. It uses an **in-memory Python list**
for storage, so there is no database, ORM, or external storage. Data resets when the server restarts.

## Project Structure

```
.
├── main.py       # Complete application
└── README.md
```

## Requirements

- Python 3.9 or higher

## Setup

```bash
# 1. Create a virtual environment
python -m venv venv

# 2. Activate it
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows

# 3. Install dependencies
pip install fastapi uvicorn
```

## Run the Application

```bash
uvicorn main:app --reload
```

The server starts at http://127.0.0.1:8000

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## API Endpoints

| #   | Method | Endpoint                 | Description        | Success | Errors   |
|-----|--------|--------------------------|--------------------|---------|----------|
| 1   | GET    | `/`                      | Welcome message    | 200     | -        |
| 2   | GET    | `/students`              | Get all students   | 200     | -        |
| 3   | GET    | `/students/{student_id}` | Get student by ID  | 200     | 404      |
| 4   | POST   | `/students`              | Create a student   | 201     | 422      |
| 5   | PUT    | `/students/{student_id}` | Update a student   | 200     | 404, 422 |

## Student Fields

| Field       | Type    | Rules                          |
|-------------|---------|--------------------------------|
| `id`        | integer | Auto-generated by the server   |
| `name`      | string  | Minimum 2 characters           |
| `email`     | string  | Must be a valid email format   |
| `course`    | string  | Minimum 2 characters           |
| `is_active` | boolean | Defaults to `true`             |

## Example Requests

**Welcome**
```bash
curl http://127.0.0.1:8000/
```
Response:
```json
{
  "message": "Welcome to FastAPI",
  "application": "Student Management API",
  "status": "running"
}
```

**Get all students**
```bash
curl http://127.0.0.1:8000/students
```

**Get student by ID**
```bash
curl http://127.0.0.1:8000/students/2
```
Returns `404 Not Found` if the student does not exist.

**Create a student**
```bash
curl -X POST http://127.0.0.1:8000/students \
  -H "Content-Type: application/json" \
  -d '{"name":"Priya Verma","email":"priya@example.com","course":"FastAPI","is_active":true}'
```
Returns `201 Created` with the new student (including the generated `id`).
Invalid data returns `422 Unprocessable Entity`.

**Update a student**
```bash
curl -X PUT http://127.0.0.1:8000/students/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"Rahul Sharma","email":"rahul@example.com","course":"Advanced Python","is_active":true}'
```
Returns the updated student, or `404 Not Found` if the ID does not exist.

## Testing with Swagger UI

1. Start the server and open http://127.0.0.1:8000/docs
2. Click an endpoint, then **Try it out**
3. Enter the input and click **Execute**
4. Verify these cases:
   - `GET /students/2` returns 200, and `GET /students/999` returns 404
   - `POST /students` with valid data returns 201
   - `POST /students` with `"email": "invalid"` returns 422
   - `PUT /students/1` with valid data returns 200, and `PUT /students/999` returns 404
